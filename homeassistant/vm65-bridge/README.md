# Motorola VM65 Bridge (Home Assistant add-on)

Packages `vm65-bridge` and `go2rtc` so a Motorola VM65 camera can be viewed in
Home Assistant over the reconstructed Magic WEB2 tunnel.

See [DOCS.md](DOCS.md) for options, usage and the current 5GenCare-credentials
limitation.

## Local add-on install

1. Copy the `homeassistant/vm65-bridge` folder into your Home Assistant
   `addons/` share (or add this repository as a custom add-on repository).
2. In Home Assistant: **Settings → Add-ons → Add-on Store → ⋮ → Repositories**,
   or find it under **Local add-ons**.
3. Install, set the options (see DOCS.md), and start.

# Motorola Nursery Bridge add-on

Connects compatible Motorola Nursery/5GenCare cameras to Home Assistant through
the Magic WEB2 relay. VM65 is the tested reference camera, not a model filter.

Add `https://github.com/Paradox101/motorola-babycam-ha-bridge` to **Settings > Add-ons
> Add-on Store > Repositories**, install **Motorola Nursery Bridge**, and follow
the pairing steps in [DOCS.md](DOCS.md).

The existing add-on slug `vm65_bridge` and `vm65` stream alias are retained for
upgrade compatibility.
